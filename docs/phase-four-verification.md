# フェーズ4の実装・検証

対象: U-02、U-09、U-10、U-13、U-15、U-20、U-24、U-27、U-28、U-29。
表示言語は日本語に統一する。

## 実装

- 空状態に新規作成、パッケージを開く、フォルダを開くボタンと最近使った文書を表示する。履歴は最大8件を端末に保存する。
- ネイティブのドロップイベントで `.mdpkg` とフォルダを開く。編集中はアプリ内で破棄を確認し、取り消すと編集を保持する。画像ドロップも取り込めるようにし、読み込み待ちの間の編集を保持する。
- 確認、リネーム、移動、パス入力を共通のアプリ内ダイアログにする。拡張子を保持し、入力の重複や不正なパスを確認する。
- ファイルをパスで絞り込めるようにし、サイドバー再表示時もフォルダの開閉状態を保持する。フォルダ選択と編集中のファイルを別に管理する。
- 空フォルダが保存されない条件を追加前に説明する。
- AI 選択操作の無効理由を表示し、操作できない場合も設定を開けるようにする。
- 文書名と未保存を示す `*` をブラウザとネイティブのウィンドウタイトルに反映する。
- manifest のリソース種別を選択式にし、未知の値は警告して保持する。
- 保存とパッケージ検索のメニューにショートカットを表示し、ヘルプに一覧を追加する。
- 通知、エラー概要、確認、検索、診断、図形編集を含む UI を日本語化する。ファイル名、本文、技術的な識別子は保持し、OS 等が返すエラー原文は詳細として残す。図形編集部品は翻訳関数を受け取れるようにし、単独利用時の既定言語を維持する。

## 検証結果（2026-11-07、Windows）

- `npm test`: 76 ファイル、714 テスト成功。リネーム、移動、削除の確認・取消、フィルタ、フォルダ選択、開閉状態、履歴、AI 設定、ヘルプ、タイトル、保存中の編集保持を含む。
- `npm run build`: 成功。既存の大きなチャンクに関する Vite の警告は残る。
- `cargo build --offline --manifest-path src-tauri/Cargo.toml`: 成功。
- `cargo test --offline --manifest-path src-tauri/Cargo.toml`: 153 テスト成功。
- 最新のフロントエンドを Windows の Tauri デバッグ版で読み込み、WebView2 上で以下を確認した。実ファイルの読み書きとネイティブウィンドウのタイトル API を使用し、JavaScript の未処理例外はなかった。
  - 日本語の空状態と3つの開始ボタン、AI の無効理由から設定を開く導線、ヘルプのショートカット一覧。
  - フォルダを開き、サイドバーを閉じて再表示しても開閉状態が残ること。絞り込みで祖先フォルダと一致したファイルが表示されること。
  - manifest の未知種別 `graphviz` が選択値として残り、警告が表示されること。
  - 入力後にネイティブタイトルが `*文書名 — MaCa Editor` となること。
  - 別パッケージを開く確認を取り消すと入力内容が残り、破棄を確定した場合だけ切り替わること。
  - 再読込後も最近使った文書が表示され、そこから実ファイルを開けること。

ドロップの実機検証では、Tauri の `tauri://drag-drop` イベントを対象 WebView に送信した。Explorer からマウスでドラッグする操作そのものは未検証。
