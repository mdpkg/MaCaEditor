## コマンドと実測

Phase 6の最終ローカル実測はTypeScript 119ファイル・1,085件、Rust 255件（Windows）、Chromium 48件、release-notes 2件が成功。型チェック、本番ビルド、architecture 140モジュールも成功した。100回の文書破棄・遅延応答テストと狭幅ヘルプの確認を含む。PRとマージ後mainのCIは、対応するSHAの実行結果を最終PRおよび作業完了報告で確認する。

標準コマンドは `npm test`、`npm run test:browser`、`npm run test:chacha-app`、`npm run build`、`npm run check:architecture`、`node --test scripts/release-notes.node-test.cjs`、`cargo test --locked --manifest-path src-tauri/Cargo.toml --lib`。独立したlintスクリプトはない。CIではfrontend、rust-windows、rust-linuxとglibセキュリティbackportテストを確認する。

この作業のローカルworktreeは既存の親node_modulesとCargo targetを再利用した。Viteの親依存参照だけを外部テスト設定／一時的fs.allowで許可し、製品設定には残していない。

PR #118の最初のWindows実行では、追加した模擬HTTPテストが既存の共通送信枠テストと競合した。共通のテスト用ロックへ揃えて修正し、最新PR CIとマージ後CIの全成功を確認した。本体の単一送信枠は緩和していない。

## 自動テストで確認していないこと

- 実機WebView2とOS固有の日本語IMEによる操作、支援技術の読み上げ、OS・ブラウザ固有の200%ズーム。
- 実LLMの読者らしさ、noneの割合、人格の自然さ、接続先内部の推論停止、実サービスの料金・保存方針。
- 人間による長時間執筆時の集中度・快適さ。反復開閉や時刻制御の成功から主観評価が済んだとは判断しない。

スクリーンショットは360pxおよびDPRとviewportによる200%相当の明暗テーマを確認する。実機ズームと同一と断定しない。時間条件5秒・30秒は初期値で、実利用の評価後に中央定数で調整できる。

2026-11-27の操作変更では、チャット欄表示だけでの抑制を解除し、ミニアイコンで本文近くの吹き出しを開き、その本文から新規引用会話へ移る操作を追加検証した。表示のみの無通信、既存下書きの保持、失効コメントの拒否、展開中の寿命、Vim・IME・Esc、360pxの明暗表示を確認する。
