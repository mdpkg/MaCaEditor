Markdown プレビューと文書ファイルのアクセス制御を強化しました。v2.5.0 の Marp 対応を引き継ぎ、安全性を改善する修正版です。

## 修正・安全性

- Markdown のリンク・画像 URL のデコードと検証を統一し、不正な URL による JavaScript 実行を遮断しました。
- SVG の外部参照と危険な CSS を表示時に除去します。拡大表示にも同じ処理を適用し、ローカルのグラデーション・マスクなどと対応する埋め込み画像は維持します。元の SVG ファイルは書き換えません。
- 本番アプリに Content Security Policy（CSP）を導入し、任意のインライン JavaScript、JavaScript eval、不許可の外部リソース取得などを制限しました。Marp の固定ランタイムだけを許可し、既存の sandbox と IPC 隔離を維持します。
- 文書を開く・保存する・作成する・インポート／エクスポートする・フォルダを監視する操作で、ネイティブ側のパス認可を確認します。アプリの設定・認可記録などの内部データも保護します。
- エディター設定を固定パスの専用コマンドで読み書きするよう変更しました。既存の設定ファイル形式と値を引き継ぎます。

## 互換性・制約

- 従来の「最近使った文書」は、初回にファイル／フォルダの再選択が必要になる場合があります。キャンセルすると現在の表示を維持します。認可済みの文書はアプリ再起動後も再度開けます。
- アプリの内部データ保存先を含むフォルダ（ホーム全体やドライブ直下など）は開けない場合があります。文書のフォルダを選択してください。
- SVG 内の外部リンク・外部画像、一部の特殊な CSS 表現や曖昧なエンコードを含むパスは表示・参照対象から除かれます。通常の許可された Markdown 外部リンクは引き続き利用できます。
- 文書モデル、manifest、Package／Folder の保存形式と依存ライブラリのバージョンは変更していません。

## 検証とリリース運用

Markdown／SVG と CSP のブラウザー回帰テストを通常の CI に追加し、Windows／WebView2 の実機検証を再実行できる専用ランナーを保存しました。変更の検証記録は [Markdown プレビューの安全性](../markdown-preview-security.md) と [Tauri の CSP・文書認可](../tauri-security.md) に記載しています。Windows の実機検証は合成文書を使用しており、macOS／Linux の GUI と実際の印刷ダイアログは未確認です。

リリース時にはフロントエンド・ブラウザー・Rust Windows／Linux の CI と、Windows・macOS Apple Silicon・Linux の配布ビルドを確認します。日本語の概要はタグ内の原稿から自動反映し、公開後に一致を検証するようにしました。
