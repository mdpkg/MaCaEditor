# MaCa Editor v2.5.0

Marp 形式の Markdown を編集し、そのままスライドとしてプレビューできるようになりました。

## 新機能

- 先頭 YAML frontmatter の boolean `marp: true` を検出して、通常 Markdown からスライド表示へ自動切り替え。
- 標準テーマ `default`・`gaia`・`uncover`、16:9／4:3、ページ番号、ヘッダー・フッター、基本ディレクティブ、オフラインの数式表示に対応。
- パッケージ内の画像、SVG 図版、背景画像を再利用。
- プレビューのみ／左右分割に対応し、編集内容を自動反映。スライド単位の双方向スクロール同期、前後移動、編集後の表示位置復元を追加。
- 画像不足・不正な frontmatter・変換失敗などの警告、エラー、再試行を表示。

## 安全性と互換性

- スライドを sandbox iframe に隔離し、文書由来の JavaScript と不許可の外部通信を遮断。
- Windows WebView2 でプレビューに Tauri API／IPC が注入されないよう、同梱ランタイムのフレーム隔離を修正。
- 通常 Markdown の表示・精密スクロール同期・印刷を維持。Document Model、manifest、Package／Folder の保存形式は変更していません。

Marp のスライド印刷・PDF／PPTX／HTML エクスポート、発表者機能、独自 CSS、任意 HTML、外部画像・フォント・CSS は今回の対象外です。

## 試し方

[Marp サンプルフォルダ](https://github.com/mdpkg/MaCaEditor/tree/v2.5.0/example/marp-example)をフォルダモードで開くか、Markdown の先頭に次の frontmatter を追加してください。

```markdown
---
marp: true
theme: default
paginate: true
---

# 最初のスライド

---

# 次のスライド
```

仕様・容量上限・位置復元の制約は [Marp プレビュー実装ノート](https://github.com/mdpkg/MaCaEditor/blob/v2.5.0/docs/marp-preview.md)を参照してください。

## 検証

Marp 対応のフロントエンド 852 件、ブラウザー 15 件、Windows Rust 227 件のテスト、および CI の frontend・Rust Windows・Rust Linux が成功しています。実 WebView2 では標準テーマ、両サイズ、数式、SVG、背景画像、編集画面との統合、iframe 隔離を確認しました。macOS／Linux の GUI 実機確認は未実施です。
