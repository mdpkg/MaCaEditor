# 茶々入れの使い方と制約

茶々入れは、執筆中の段落に短い感想・助言・指摘を返す読者です。本文を編集せず、コメントに対応する必要もありません。初期状態は無効です。

## 有効化・停止

1. **AI → AI 設定** で OpenAI 互換の接続先とモデル、必要なら API キーを保存します。
2. 文書を開き、ステータスバーの **茶々入れ：無効** を押します。
3. 接続先、モデル、送信範囲、頻度、利用料金の説明を確認し、**自動送信を有効にする** を押します。

有効化だけでは送りません。その後の編集量と入力停止条件を待ちます。同じパッケージのファイル切替では同意を維持しますが、編集中の要求とコメントは破棄します。別文書、文書を閉じる、再起動、保存先が変わる操作では再同意が必要です。接続先・モデル・認証情報などの接続設定変更でも自動送信を停止します。

ステータスバーの有効表示で一時停止、停止表示で再開できます。**AI 設定** の茶々入れ欄から無効化もできます。停止すると通信のキャンセルを試み、遅延応答とコメントを破棄します。再開しても停止中の編集をまとめて送りません。

## 頻度と人格

| 頻度 | 送信開始間隔 | 最低編集量 | 入力停止 |
|---|---:|---:|---:|
| 控えめ | 300秒 | 250文字 | 8秒 |
| 標準（初期値） | 120秒 | 100文字 | 5秒 |
| 多め | 60秒 | 50文字 | 3秒 |

挿入と削除の合計を数え、IME は確定した差分だけ数えます。ファイルを開く、カーソルを動かす、スクロールするだけでは送信しません。初回も編集量と入力停止は必須です。コメントや応答待ちがある間は新しい要求を開始しません。同じファイルの同じ送信文脈をセッション内で繰り返し送らないよう抑制します（直近128件）。

**AI 設定 → 茶々入れ** で頻度と **読者の人格・口調** を編集し、**茶々入れ設定を保存** を押します。人格は最大10,000 Unicode文字、空欄は初期の親しい友人です。**初期プロンプトに戻す** は入力欄を戻す操作なので、その後に保存してください。未保存の変更は閉じると破棄します。

人格と頻度はアプリ設定に保持され、他の AI のプロンプトを変更しません。保存後は再起動なしで反映し、旧設定の応答を破棄します。アプリ固定の形式・長さ・操作禁止の制約は人格設定より優先されます。

## 何を送るか

直前に実際に編集した Markdown の段落と、前後各1段落・直近の見出しだけです。合計2,000 Unicode文字までで、補助文脈を先に省略します。対象段落だけで上限を超える場合は見送ります。別ファイル、画像・添付、manifest、チャット履歴は読み込みません。

frontmatter、コードブロック、HTML、画像とリンクの宛先は除外します。インラインHTMLを含む段落やローカル絶対パスの疑いがある段落も見送ります。POSIXパスが日本語に続く場合も除外するため、プレーンテキストに `/` を含む段落は保守的に対象外です。`A/B`、裸のURLなども見送ることがあります。Markdownリンクは宛先を除いた表示文字だけが候補になります。

文章は設定した LLM 接続先へ送られます。接続先の料金・データ取扱いを確認してください。アプリの API キーは既存の資格情報ストアと通信認証で使用し、文書文脈や診断ログには含めません。文書内に自分で書いた秘密情報すべてを検知する機能ではありません。

## 読む・無視する・削除する

右ガターの 💬 を押すまで本文は表示しません。到着時にフォーカスや選択・スクロールを変えず、通知音やトーストも出しません。無視して書き続けられます。

| 操作 | Windows/Linux | macOS |
|---|---|---|
| 展開して読む | Ctrl+Alt+Enter | Cmd+Alt+Enter |
| 削除 | Ctrl+Alt+Backspace | Cmd+Alt+Backspace |
| 通常時の削除 | 他の操作が使わない Esc | 同左 |

× は未展開・展開中の両方で削除できます。キーボードで展開するとコメントへフォーカスを移し、Esc/削除でエディタへ戻します。マウス展開では執筆フォーカスを維持します。Vim有効時はエディタ内のEscを茶々入れで処理しません。IME・補完・検索・ダイアログを優先します。

未展開は表示から180秒、表示待ちは受信から30秒で失効します。展開中は時間だけでは消えません。対象または送信文脈の変更、画面外への移動、ファイル切替、停止などでは消えます。削除したコメントは Undo/Redo で復活せず、本文・dirty状態・保存データ・履歴へ入りません。

## 反応が出ないとき

有益な反応なし、形式不正、120文字超過は表示せず終了します。入力、IME、補完、検索、ダイアログ操作中や非アクティブウィンドウでは送信・新規表示を待ちます。本文を整形して自動修復したり再送したりしません。

通信全体は60秒、出力は256トークン、通信応答8KiB・生成テキスト4KiBまでです。既存の明示 AI は既定300秒ですが、自動通信は専用の60秒上限に固定し、接続段階は保存済み接続タイムアウト（最大60秒）を使います。自動リトライはありません。

認証エラー、レート制限、連続3回の通信失敗では一時停止します。停止理由は **AI 設定** で確認できます。レート制限は Retry-After の待機後に明示再開してください。単発の失敗では通常編集を継続できます。明示的な AI 操作の開始時は茶々入れをキャンセルし、明示操作を優先します。

## 検証と実機確認

実ブラウザと Fake LLM による検証範囲は [検証記録](chacha-verification.md)、実装構造は [設計書](chacha-design.md) を参照してください。OSの日本語IME、支援技術、実際の接続先での自然な反応、長時間執筆の主観的な快適さは実機確認が必要です。
