# 茶々入れの使い方と制約

茶々入れは、執筆中の文章にときどき感想・疑問・助言・指摘を返す読者です。本文を自動編集せず、反応に対応する必要もありません。何も言わない `none` も自然な結果です。

## 有効化と送信範囲

初期状態は無効です。AI設定に接続先・モデル・必要なAPIキーを保存し、文書を開いてステータスバーの「茶々入れ：無効」を押します。接続先・送信範囲・時間条件・料金の説明を確認して「自動送信を有効にする」を選びます。有効化だけでは送りません。

送るのは実際に編集したMarkdownの段落と、前後各1段落・直近の見出しだけで、合計2,000 Unicodeコードポイントまでです。補助文脈を先に省略し、対象段落だけで超える場合は見送ります。別ファイル・画像・添付・manifest・チャット履歴は読みません。

frontmatter、コードブロック、HTML、画像やリンクの宛先は除外します。インラインHTMLやローカル絶対パスの疑いがある段落も見送ります。本文中の `/` は保守的に除外するため、`A/B` や裸のURLを含む段落も対象外になる場合があります。文書内の秘密情報すべてを検知する機能ではありません。

## 発生するタイミング

最低編集文字数はありません。1文字の追加・変更・削除、貼り付け、Undo／Redoによる本文変更も対象です。本文が変わらない置換、カーソルや選択・スクロールだけの操作では送りません。

実行可能時刻は `max(最終編集 + 5秒, 前回の要求開始 + 30秒)` です。連続編集は5秒の待機を更新し、クールダウン中の候補は最新の文脈に集約します。有効な候補が残っていれば、30秒満了後に追加編集がなくても一度だけ評価します。`none`・エラー・キャンセルでも開始済み要求の間隔は守り、自動再試行しません。

同じ文書・ファイル・生成設定で、実際に送った限定文脈を繰り返し送りません。記録は直近128件です。人格や接続設定の変更だけで自動送信を始めません。旧「控えめ／標準／多め」の頻度プリセットは使用しません。

IME未確定、補完・検索・モーダル、非アクティブウィンドウ、明示AI操作中などは抑制します。AIチャットを表示している間と、閉じていてもチャットが接続中・生成中・停止終了待ちの間も抑制します。抑制中の編集や古い候補を解除時にまとめて送らず、解除後の新しい本文変更から再開します。IMEは確定した実差分から評価します。

## 人格・停止・寿命

AI設定の「読者の人格・口調」を編集し、「茶々入れ設定を保存」で適用します。最大10,000 Unicodeコードポイント、空欄は初期の親しい友人です。「初期プロンプトに戻す」の後も保存が必要です。未保存入力は閉じると破棄されます。人格だけをアプリ設定に保存し、他のAIの人格には適用しません。

ステータスバーの有効表示で一時停止、停止表示で再開できます。AI設定から無効化もできます。停止は要求・コメント・候補を失効させ、再開後の編集から評価します。認証エラー、レート制限、連続3回の通信失敗では一時停止します。レート制限はRetry-Afterの待機後に明示再開してください。

同じパッケージのファイル切替では同意を保ち、編集中の要求と吹き出しは破棄します。文書を閉じる・置き換える・再起動する操作では解除します。自動茶々入れは保存先変更時にも再同意が必要です。接続先・モデル・認証情報などの設定変更でも再同意を求めます。チャットの会話タブは同じ文書の名前を付けて保存では保持されます。

## 吹き出しから会話する

右ガターの💬に反応が届いても、フォーカス・選択・本文・履歴を変更せず、通知音やトーストを出しません。無視して執筆を続けられます。ボタンのtitleと説明で反応全体を確認できます。

💬または `Ctrl/Cmd+Alt+Enter` で、その反応の引用会話タブを開きます。旧ポップオーバーの展開は廃止しました。生成時の対象段落・送った補助文脈・人格・元の反応を固定し、追加質問を送るまで通信しません。固定カードのdetailsで送信する補助文脈と人格を確認できます。後の本文編集・削除・人格変更でも固定引用は変わりません。

作成・選択に成功してから吹き出しを消します。会話が20件などで作成できない場合は通知し、吹き出しを残します。文書全文を送る通常相談とは別で、生成時の接続revisionが現在と違う場合は初回送信前にもその会話の確認が必要です。詳しくは[チャット設計](ai-chat-design.md)を参照してください。

吹き出しだけの削除は×または `Ctrl/Cmd+Alt+Backspace`。他の操作が使わないEscでも削除できます。IME・補完・検索・モーダル・VimのEscを優先します。到着後180秒、表示待ち30秒で失効し、文脈変更・画面外・ファイル切替でも消えます。削除をUndoして復活することはありません。

## 通信上限と確認範囲

自動通信は全体60秒、接続は保存値と60秒の小さい方、出力256トークン、HTTP応答8KiB、生成テキスト4KiBまでです。既知の種別と最大120文字の反応だけを表示し、不正な応答は修復・再送しません。引用会話の追加回答には、この自動生成用の短文・JSON・none制約を適用しません。

コメントと有効化状態は文書や保存履歴に入りません。会話もメモリだけです。接続先内部の推論停止まで保証するものではありません。模擬通信による自動検証と、OS IME・実機WebView2・支援技術・長時間執筆・読者の自然さの確認は[検証記録](chacha-verification.md)で区別しています。
