# MaCa Editor

MaCa Editorは、[Markdown Package Specification（mdpkg仕様）](https://github.com/mdpkg/mdpkg-spec)に則った `.mdpkg` ファイルを閲覧・編集するためのデスクトップエディタです。

名称の **MaCa** は、**Ma**rkdownと**Ca**nvasに由来します。Markdown文書の編集とSVGベースの作図を1つのアプリケーションで行い、文章、画像、図、添付ファイルをまとめて管理できます。

## ダウンロード

Windows x64 用の `.exe` または `.msi`、macOS Apple Silicon 用の `.dmg`、Linux x86-64 用の AppImage・`.deb`・`.rpm` を配布しています。[MaCa Editor 最新版のダウンロード](https://github.com/mdpkg/MaCaEditor/releases/latest)

v2.2.0 では、保存中の編集の保護、外部変更からの復旧、キーボード操作と検索、日本語のエラー表示を改善しました。長い Markdown 文書のプレビュー描画も高速化し、印刷にヘッダとページ番号を追加しました。[レビュー対応と検証範囲](review/README.md)

## 主な機能

### Markdownの編集とプレビュー

- Markdownファイルの編集とリアルタイムプレビュー
- CodeMirrorによるMarkdown編集
- 標準モードとVim modeの切り替え（Vim modeでは`:w`で保存）
- GitHub Flavored Markdown（GFM）対応
- テーブル、タスクリスト、取り消し線、URL自動リンク
- GitHub Flavored Markdown Alerts（`> [!NOTE]`など）の表示
- YAML front matterをキー・値の表として表示
- Rspressモードでの`:::`コンテナ表示
- チェックボックスで切り替えられる目次（TOC）表示
- プレビュー上のテーブルをクリックしてGUIで編集
- テーブルの任意位置に行・列を挿入、TSV・Markdownテーブルの貼り付け（列の配置も反映）
- 日本語や空白を含む画像ファイル名への対応
- GitHub風のプレビュースタイル
- ファイルツリーのMarkdownファイルをダブルクリックして編集
- ツールバー左端のボタンでファイルリストを開閉
- 画像とダイアグラムの全画面拡大、ズーム、パン
- ヘッダとページ番号付きの印刷、および OS の印刷機能を利用した PDF 保存
- 目次、Rspress、Vim モードの設定を次回起動時に復元
- 前回終了時のウィンドウ位置・サイズを次回起動時に復元

### ファイルと画像の管理

- MDPKG v2対応（新規Documentのentrypointは`index.md`）
- MDPKG v1の読み込みと、保存時のv2への移行
- `.mdpkg` の新規作成、読み込み、保存、別名保存
- フォルダからのインポートとフォルダへのエクスポート
- ファイルツリーの絞り込み、キーボード操作、文書ごとのフォルダ開閉状態の復元
- ファイルツリーにFolder、Markdown、Image、Diagram、その他ファイルの種別アイコンを表示
- Markdownとフォルダの追加
- PNG、JPEG、GIF、WebP、BMP画像の追加
- 任意形式の添付ファイルを1つまたは複数まとめて追加
- `.mdpkg` やフォルダをドロップして開き、開いている文書へ画像をドロップして取り込み
- ファイルやフォルダのリネーム、移動、削除
- ファイルツリーの右クリックメニューからMarkdownとフォルダを追加
- ファイルツリー内のドラッグ＆ドロップによるファイルやフォルダの移動
- リネームまたは移動時に、パッケージ内Markdownリンクを自動更新
- インラインリンク、画像リンク、参照形式リンクに対応したMarkdown ASTベースのリンク解析
- ファイルツリーからMarkdownエディタへドロップしてリンクを挿入
- `Ctrl`／`Cmd`+クリックによるMarkdownリンク先への移動
- ファイルツリーから参照元（backlink）を表示
- 壊れたリンクのエディタ上での強調表示
- ファイル操作のUndo／Redoと、削除前の影響リンク数表示
- パッケージ全体の診断と検索
- manifestのdescriptionとresource関連付けの編集
- 図source／renderedペアの一括移動・削除と、再生成が必要な図の検出
- 画像やダイアグラムのリンクを、Markdownのカーソル位置または末尾へ挿入
- 添付ファイルのリンクをMarkdownへ挿入し、プレビューから保存先を指定してダウンロード
- 添付ファイルのダウンロード開始、完了、失敗を画面右上のバナーで通知

### 図形エディタ

- 矩形、角丸矩形、楕円、円柱、キューブ、吹き出し、ファイル、ユーザー、テキスト、画像
- フローチャート記号、各方向の矢印、円弧矢印、左右の波括弧
- 直線、矢印、直線コネクタ、曲線コネクタ、カギコネクタ
- オブジェクトの選択、複数選択、移動、リサイズ、回転
- グリッド表示、スナップ、ズーム、描画エリアのサイズ変更
- 移動中に図形の端・中心へ吸着するスマートガイド（**ガイド**で切り替え、Altで一時解除）
- グリッド・スナップ・ガイドのオン／オフを記憶し、作図画面の再表示・アプリ再起動時に復元
- 3個以上の図形を選択し、**プロパティ**の **横の間隔**／**縦の間隔** で水平・垂直の余白を等間隔に配置
- コピー、貼り付け、複製、削除、Undo、Redo
- 前面・背面への移動と整列
- グループ化、グループ解除、ネストしたグループ
- ダブルクリックによるグループ内要素の個別選択
- 塗りつぶし、線色、透明度、太さ、線スタイル
- コネクタ両端の矢印・鳥足と、小・中・大の端点サイズ設定
- コネクタの接続位置をシェイプの輪郭上で自由に調整し、別のシェイプへ付け替え
- コネクタの複数行ラベル（**プロパティ**の **ラベル**、または線をダブルクリックして編集）。直線・曲線・カギ線の移動に追従し、SVGにも出力
- 吹き出しのしっぽ、円弧矢印の角度と両端をGUIハンドルで調整
- シェイプ内の複数行テキストと水平・垂直配置
- SVGへの画像追加
- Markdown プレビュー上の図に表示される **編集** ボタン、またはダブルクリックで再編集

### PlantUML・Mermaid・MathJax

- PlantUMLとMermaidのダイアグラム、およびMathJaxの数式を新規作成
- テキスト形式の定義とSVGプレビューを左右に並べて表示
- 入力内容に合わせたプレビューの自動更新
- 構文エラーの表示
- Markdownのカーソル位置または末尾へダイアグラムを挿入
- Markdownプレビュー上のダイアグラムをダブルクリックして再編集
- PlantUML・Mermaid・MathJax編集画面のSVGプレビューをクリックして全画面拡大
- PlantUMLは`plantuml.js`、Mermaidは`mermaid.js`、数式はMathJaxを使用し、アプリ内でSVG描画

## 基本的な使い方

### `.mdpkg` を編集する

1. 開始画面の **開く** で `.mdpkg` を選択します。開始ファイルが分割編集画面で開き、本文に入力できます。ウィンドウへのドロップや **最近使った文書** からも開けます。
2. 別の Markdown を編集するには、ファイルツリーでダブルクリックするか、選択したファイルのプレビューで **編集** を押します。
3. **ファイル** → **保存**、または `Ctrl+S`（macOS では `Cmd+S`）で保存します。保存中に入力した変更は未保存の編集として残り、次の保存で反映されます。

ツールバー右側では、目次を表示する **目次**、Rspressの`:::`構文を有効にする **Rspress**、Vimキーバインドを有効にする **Vim モード** を切り替えられます。これらの設定は次回起動時にも引き継がれます。

アプリ終了時のウィンドウ位置とサイズも保存され、次回起動時に復元されます。

ツールバー左端の **☰** を押すと、左側のファイルリストを閉じて編集領域を広げられます。もう一度押すとファイルリストを再表示します。サイドバーと分割編集画面の境界をドラッグして幅を調整でき、設定は次回起動時にも引き継がれます。

### 展開済みフォルダを編集する（フォルダモード）

1. **ファイル** → **フォルダを開く...** で、展開済みmdpkgフォルダまたは既存のMarkdownフォルダを選択します。
2. 通常どおりMarkdown、画像、Drawingなどを編集します。
3. **保存** で変更・追加・名前の変更・削除を選択したフォルダへ直接反映します。
4. 配布用の `.mdpkg` は **ファイル** → **パッケージに書き出し...** で生成できます。書き出し後もフォルダの編集を続けられます。

ステータスバーには現在の **パッケージ** または **フォルダ** モードが表示されます。フォルダを外部で変更したときは、未保存の編集がなければ自動で再読込します。競合が発生すると、フォルダへの保存を一時停止し、編集内容を保持します。バナーの **パッケージに書き出し...** で編集を `.mdpkg` へ退避し、**フォルダを再読込...** の確認画面で再読込を確定できます。再読込を取り消すと編集内容が残ります。

選択したフォルダに`manifest.json`がない場合は、Markdownとそのリンクを解析してMDPKG v2 manifestの候補を生成します。entrypointは`index.md`、`README.md`、パス順で最初のMarkdownの順に選択されます。参照された`.svg`／`.png`と同名の`.draw.json`、`.puml`、`.mmd`、`.tex`、`.dot`がある場合は図resourceとして関連付けます。確認画面ではentrypointとresourceを修正でき、壊れたリンク、フォルダ外リンク、曖昧な図sourceは警告されます。フォルダを直接開いた場合は、最初の保存時に `manifest.json` を書き込みます。**フォルダから取り込み** では、生成した manifest を新しい `.mdpkg` に格納します。

manifest生成時は、大規模な依存・生成物を誤って取り込まないよう、`.git`、`.hg`、`.svn`、`.next`、`node_modules`、`target`、`dist`、`build`、`coverage`ディレクトリを走査対象から除外します。

新しい文書をフォルダモードで作成するには、**ファイル** → **新しい空のフォルダで開始**を選びます。親フォルダを選択して新規フォルダ名を入力すると、そのフォルダにMDPKG v2の`manifest.json`とentrypointの`index.md`が生成され、すぐに編集を開始できます。入力した名前のフォルダが既に存在する場合はエラーとなり、上書きされません。

MDPKG v1は引き続き読み込めます。v1 Documentを保存すると、既存のentrypointを維持したままmanifestのversionが`2.0`へ更新されます。
保存前には移行内容を確認するダイアログが表示され、元ファイルを更新するか、v2のコピーとして別名保存するかを選択できます。

### 新しい `.mdpkg` を作成する

1. 開始画面または **ファイル** メニューの **新規作成** で、作成する `.mdpkg` の保存先を指定します。
2. `index.md` を編集し、必要に応じて画像や図を追加します。
3. **ファイル** → **保存** で変更を書き込みます。別のパッケージに保存するには **名前を付けて保存** を使います。

**ファイル** → **Markdown を追加...**および**フォルダを追加...**で階層を追加できます。ファイルツリーのファイルまたはフォルダを右クリックして、**名前を変更**、**移動**、**削除**のほか、**Markdown を追加**、**フォルダを追加**を実行できます。Markdownでは**開始ファイルに設定**も選択できます。右クリックしても、現在メイン画面で開いているファイルは切り替わりません。

ファイルやフォルダは、ファイルツリー内で移動先のフォルダへドラッグ＆ドロップして移動することもできます。リネームまたは移動では、既存Markdown内のパッケージ内リンクが自動更新されます。削除されたファイルへのリンクは自動削除されません。パッケージ内の空フォルダを保存するには、フォルダ内にファイルを追加してください。

ファイルツリーから編集中のMarkdownへファイルをドラッグ＆ドロップすると、ドロップ位置へ相対リンクを挿入できます。Markdownと`attachments`内のファイルは通常リンク、`diagrams`と`images`内のファイルは画像リンクとして挿入されます。

Markdownエディタ上のパッケージ内リンクを`Ctrl`+クリック（macOSでは`Cmd`+クリック）すると、リンク先のMarkdownを開けます。ファイルツリーの**参照元を表示**では、そのファイルを参照しているMarkdownと行番号を確認できます。存在しないリンク、パッケージ外へ出るリンク、大文字・小文字が一致しないリンクはエディタ上で波線表示されます。

**ファイル** → **元に戻す**／**やり直し** では、Markdown の編集やファイルの移動など、文書への変更を同じ履歴で取り消し・やり直しできます。文書を開き直すと、最後に保存した時点の履歴が復元されます。

### パッケージを検証する

**ファイル** → **パッケージを診断...**を選択すると、次の問題をパッケージ全体から検出します。

- 存在しないリンク、パッケージ外へ出るリンク、ファイル名の大文字・小文字の不一致
- manifest resourceの不正またはsource／renderedファイルの欠落
- source更新後にrenderedが再生成されていないresource
- 未参照ファイル
- 不正なパス、Unicode正規化後のパス衝突
- UTF-8として読み込めないMarkdown

結果を重大度で絞り込み、行をクリックして該当箇所を開けます。

### パッケージを検索する

**ファイル** → **パッケージを検索...**では、次の検索方法を選択できます。

- ファイル名
- 全文
- Markdown見出し
- リンク先
- 指定したパッケージ内パスへの参照元

検索結果はクリック、または矢印キーで選んで `Enter` で開けます。現在の Markdown だけを検索するには `Ctrl+F`（macOS では `Cmd+F`）を使います。

### manifestを編集する

**ファイル** → **manifest を編集...**では、entrypoint、`description`と`resources`の`type`、`source`、`rendered`を編集できます。entrypointにはパッケージ内のMarkdown、resourceにはパッケージ内に存在するファイルだけを指定できます。未知のリソース種別は警告し、元の値を保持します。アプリが認識しない manifest の追加フィールドも保存時に維持されます。

manifestで関連付けられた図sourceとrenderedファイルは、片方を移動または削除するとペアで処理されます。sourceを編集したあとrenderedがまだ更新されていない場合は、パッケージ診断に警告が表示されます。

### 画像を追加する

1. Markdownの挿入位置へカーソルを置きます。
2. **画像を追加** を押して画像を選択します。
3. 画像のリンクがカーソル位置へ挿入されます。カーソル位置がない場合はMarkdownの末尾へ挿入されます。

画像、図、添付ファイルは、リンクを挿入するMarkdownと同じディレクトリ内の`images`、`diagrams`、`attachments`へ保存されます。開いている文書の本文領域や、ファイルツリーの対象の `images` フォルダへ画像をドロップしても追加できます。混在するドロップでは、取り込んだ画像、除外したファイル、読み込めなかったファイルの件数と対象名を通知で確認できます。

### 添付ファイルを追加する

1. Markdownの挿入位置へカーソルを置きます。
2. **添付ファイルを追加** を押して、添付するファイルを選択します。複数のファイルを一度に選択することもできます。
3. 選択したファイルはファイルツリーの `attachments` に追加され、それぞれのリンクがカーソル位置へ挿入されます。カーソル位置がない場合はMarkdownの末尾へ挿入されます。
4. Markdownプレビュー上のリンクをクリックし、保存先を選ぶと添付ファイルをダウンロードできます。
5. ダウンロードの開始、完了、失敗は、画面右上のバナーで通知されます。

### 図を追加する

1. Markdownの挿入位置へカーソルを置きます。
2. **図を挿入** メニューから **SVG** を選択します。
3. Drawing Editorで図を作成します。
4. 図のリンクがMarkdownのカーソル位置へ挿入されます。カーソル位置がない場合は末尾へ挿入されます。
5. Markdown プレビュー上の **編集** を押すか、図をダブルクリックすると、再び図形エディタで編集できます。

PlantUML、MermaidまたはMathJaxの数式を作成する場合は、**図を挿入** メニューから該当する形式を選択します。表示されたテキストエディタへ定義またはTeX形式の数式を入力すると、右側のSVGプレビューが自動更新されます。

### 画像・ダイアグラムを拡大表示する

- Markdownの表示画面または分割編集画面で、画像やダイアグラムをクリックすると全画面で拡大表示します。
- PlantUML・Mermaid・MathJax編集画面では、右側のSVGプレビューをクリックすると拡大表示します。
- マウスホイールで拡大・縮小し、左ドラッグで表示位置を移動できます。
- `Esc`または右上の **×** で元の画面へ戻ります。
- Markdown から開いた図は、拡大表示の **編集** ボタンやダブルクリックで編集画面に移動できます。

### 拡張Markdownをプレビューする

GitHub Flavored Markdown Alertsは常に表示できます。

```markdown
> [!WARNING]
> この操作は取り消せません。
```

Rspress形式のコンテナを表示するには、ツールバーの **Rspress** をONにします。`note`、`tip`、`important`、`info`、`warning`、`danger`、`caution`、`details`を利用でき、タイトルも指定できます。

```markdown
:::tip ヒント
ここに説明を書きます。
:::
```

### 目次を表示する

ツールバーの **目次** をオンにすると、Markdown の見出しから目次を生成してプレビューの先頭に表示します。本文に書いた「目次」節もそのまま表示されます。

### プレビューを印刷・PDF保存する

**ファイル** → **印刷** で、Markdown プレビューをヘッダとページ番号付きで印刷できます。ページ番号は「現在ページ / 総ページ数」です。PDF にする場合は、Windows では **Microsoft Print to PDF** などの PDF プリンター、macOS では印刷ダイアログの PDF 保存、Linux の GTK 印刷ダイアログでは **ファイルに出力** を選択します。

Windows で印刷ジョブの失敗を検出すると、エラーバナーとステータスバーに日本語の概要が表示されます。**詳細** で Windows のエラー原文を確認でき、バナーを閉じた後もステータスバーの **エラーの詳細** から開き直せます。

### 表を追加・編集する

- Markdownプレビュー上の表をクリックすると、表編集画面へ移動します。
- 表編集画面では、セルの直接編集、行と列の追加・削除、列の左・中央・右揃え、TSVの貼り付けができます。
- **完了** を押すと、編集結果をMarkdownへ反映して分割編集画面へ戻ります。
- **キャンセル** を押すと、表の下書きを破棄して分割編集画面へ戻ります。
- `Ctrl+Z`または`Cmd+Z`で表編集の操作を取り消せます。

### ファイルやフォルダを整理する

1. ファイルツリーで対象のファイルまたはフォルダを右クリックします。
2. **名前を変更**、**移動**、または**削除**を選択します。

ファイルやフォルダはツリー内でドラッグ＆ドロップして移動できます。パッケージのルートへドロップすると確認画面が開きます。名前の変更や移動に合わせて Markdown 内の参照も更新されます。

### フォルダとの間で入出力する

- **ファイル** → **フォルダから取り込み**: フォルダの内容から `.mdpkg` を作成します。`manifest.json`がなければMarkdownとリンクから候補を生成します。
- **ファイル** → **フォルダへ書き出し**: 開いている `.mdpkg` の内容をフォルダへ出力します。
- **ファイル** → **フォルダを開く...**: 展開済みの mdpkg フォルダを直接編集します。
- **ファイル** → **新しい空のフォルダで開始**: 新しい mdpkg フォルダと初期ファイルを作成します。
- **ファイル** → **パッケージに書き出し...**: 編集中のフォルダを検証し、配布用の `.mdpkg` を生成します。

### 安全でないパッケージの読み込みを防ぐ

ZIP Slipとパストラバーサルに加え、重複パス、区切り文字またはUnicode正規化後に衝突するパス、過大なファイル数・展開サイズ、異常な圧縮率を持つZIPを読み込み時に拒否します。現在の上限は10,000エントリ、1ファイルあたり128 MiB、合計展開サイズ512 MiBです。

### 通知を見直す

ステータスバーの **通知履歴** から、アプリの起動中に表示された直近の通知を確認できます。自動で消えた通知や、閉じたエラーの原文も確認できます。

### AI を設定する

ツールバーの **AI** → **AI を設定する** または **AI 設定** で、OpenAI 互換の接続先、モデル、必要に応じて API キーを設定します。**接続をテスト** で接続を確認できます。設定後は、選択範囲の **書き換え**・**要約**・**校正**、文書についての **AI チャット**、PlantUML・Mermaid エディタの **AI で生成** を利用できます。失敗時は日本語の概要と **詳細** を確認できます。

## 図形エディタの操作

### オブジェクトを作成する

ツールバーからシェイプ、線、コネクタ、テキスト、画像のいずれかを選び、描画エリアをクリックまたはドラッグします。オブジェクトを1つ作成すると、自動的に選択モードへ戻ります。

### オブジェクトを選択する

- クリックすると1つのオブジェクトを選択します。
- `Ctrl`を押しながらクリックすると複数選択できます。
- 何もない場所から範囲をドラッグすると、範囲内に完全に収まるオブジェクトを選択します。
- グループをダブルクリックすると、グループ内のオブジェクトを個別に選択できます。

### オブジェクトを編集する

- ドラッグして移動します。
- 選択枠のハンドルをドラッグしてサイズを変更します。
- 選択枠上部の回転ハンドルをドラッグして回転します。
- **プロパティ**または右クリックメニューから色、線、透明度、テキスト配置、前面・背面を変更します。
- 複数選択したオブジェクトはまとめて移動、整列、グループ化できます。

### コネクタを編集する

- コネクタを選択すると、始点と終点に白い接続位置ハンドルが表示されます。
- 接続位置ハンドルをドラッグすると、接続先シェイプの輪郭上で位置を自由に変更できます。シェイプを移動、リサイズ、回転しても相対的な接続位置は維持されます。
- 接続位置ハンドルを別のシェイプ上へドラッグすると、接続先をそのシェイプへ付け替えます。
- 接続位置ハンドルをダブルクリックすると、位置指定を解除して自動接続へ戻します。
- **プロパティ**または右クリックメニューの **始点**／**終点** で矢印や鳥足を選択し、**始点の大きさ**／**終点の大きさ** で端点ごとに **小**／**中**／**大** を設定できます。
- 接続位置と端点設定は、直線、曲線、カギ線の各コネクタで共通です。

## キーボードショートカット

アプリ内では **ヘルプ** → **キーボードショートカット** から確認できます。

### アプリケーション

| 操作 | キー |
|---|---|
| 保存 | `Ctrl+S` / `Cmd+S` |
| 現在の Markdown 内を検索 | `Ctrl+F` / `Cmd+F` |
| パッケージ全体を検索 | `Ctrl+Shift+F` / `Cmd+Shift+F` |
| ツリーやメニュー内を移動 | 矢印キー、`Home`、`End` |
| 選択したファイルを開く | `Enter` |
| メニューやダイアログを閉じる | `Esc` |

### 図形エディタ

| 操作 | キー |
|---|---|
| 削除 | `Delete` / `Backspace` |
| コピー | `Ctrl+C` |
| 貼り付け | `Ctrl+V` |
| 複製 | `Ctrl+D` |
| Undo | `Ctrl+Z` |
| Redo | `Ctrl+Y` |
| 移動 | 矢印キー |
| 大きく移動 | `Shift` + 矢印キー |
| ズーム | `Ctrl` + マウスホイール |
| 複数選択 | `Ctrl` + クリック、または範囲ドラッグ |

テキスト入力欄へフォーカスがある場合、`Backspace`などの文字編集キーはシェイプ操作には使用されません。

## 現在対応していない機能

- Graphvizなど、SVG・PlantUML・Mermaid・MathJax以外の図形式
- draw.io、Excalidraw、PowerPointとのインポート／エクスポート
- 専用のHTMLエクスポート、および印刷ダイアログを介さない直接PDFエクスポート
- リアルタイム共同編集やクラウド同期
