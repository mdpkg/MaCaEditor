## 実装と検証の概要

35件のレビュー対応は完了しました。利用できる環境で確認できなかった条件は、対象と確認済みの範囲を分けて記録しています。[完了の判定と検証範囲](improvement-plan.md#レビュー対応の完了)

## 追補の確認結果

- U-20 は、AI 未設定時のメニューを「AI を設定する」に切り替えます。Windows で設定保存後の操作復帰と読込失敗時の案内を確認しました。[実機検証](improvement-plan.md#windows-の-ai-未設定メニューの検証2026-11-08) · [PR #38](https://github.com/mdpkg/MaCaEditor/pull/38)
- U-13 は選択行までツリーを自動でスクロールします。Windows 版を再起動し、パッケージとフォルダの開閉状態を文書ごとに復元できることを確認しました。[実機検証](improvement-plan.md#windows-のファイルツリーの選択位置と開閉状態の検証2026-11-08) · [PR #39](https://github.com/mdpkg/MaCaEditor/pull/39)
- U-02 は移動先をフォルダツリーで選び、Markdown とフォルダをツリー内で追加できます。Windows で移動によるリンク更新と、新しい Markdown の保存まで確認しました。[実機検証](improvement-plan.md#windows-の移動先ツリーとインライン追加の検証2026-11-08) · [PR #40](https://github.com/mdpkg/MaCaEditor/pull/40)
- U-04 は、ステータスバーの「通知履歴」に起動中の直近50件を表示します。Windows 実機で、自動消去・手動終了後に通知とエラー原文を確認できました。[実機検証](improvement-plan.md#windows-での通知履歴の検証2026-11-08) · [PR #37](https://github.com/mdpkg/MaCaEditor/pull/37)
- U-23 は、バナーを閉じた後にステータスバーからエラーの概要と原文を開き直せるようにしました。Windows 実機で再保存に成功すると詳細のボタンが消え、編集内容が保存されることを確認しました。[実機検証](improvement-plan.md#windows-でのエラー詳細の再表示2026-11-08) · [PR #36](https://github.com/mdpkg/MaCaEditor/pull/36)
- U-07 は Windows 実機で、短い本文と表付きの長い本文を1ファイルと100ファイルの4条件で比較しました。短い本文の100ファイル条件で、入力からプレビュー描画までの中央値は 176.4 ms → 10.0 ms、長い本文の100ファイル条件では 377.8 ms → 170.2 ms でした。[Windows 実機の計測条件と結果](improvement-plan.md#windows-での-u-07-入力性能の比較2026-11-08)
- U-07 の表付き長文は、表解析の依存パッケージを更新し、編集のたびに見出しと表を作り直す処理を解消しました。同じ4条件の Windows 実機再計測では、表付き長文の中央値が1ファイルで 168.4 ms → 69.1 ms、100ファイルで 165.6 ms → 164.1 ms でした。100ファイル条件では計測の巡ごとに差があり、p95 は増加しました。[追補の実機計測](improvement-plan.md#windows-での-u-07-表付き長文の描画改善2026-11-08) · [PR #34](https://github.com/mdpkg/MaCaEditor/pull/34)
